Cricbuzz LiveStats Project

Project Objective:
This project is a cricket analytics dashboard built using Python, SQL, SQLite, Streamlit and Cricbuzz API.

Tools Used:
Python
SQLite
SQL
Pandas
Streamlit
Requests
RapidAPI Cricbuzz API

Features:
1. Home page
2. Live/upcoming cricket fixtures from API
3. Top player statistics
4. Player data page
5. Match data page
6. SQL analytics page
7. CRUD operations for player data
8. Documentation page

Database Tables:
players
matches
venues
batting_stats
bowling_stats
series
partnerships
api_fixtures

How to Run:
1. Open Anaconda Prompt
2. Navigate to the project folder
3. Run this command:
   streamlit run main.py

Note:
To use live API data, add your RapidAPI key in the Live Matches section of main.py.
